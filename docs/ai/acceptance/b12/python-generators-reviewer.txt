Before discussing generators, it's important to understand the following concepts:.

The next() function
Once we have defined our generator expression, we make use of the 'next()' function to receive a new value from our generator.
- The syntax for this is as follows:
- next(iterator,[default])
- If the iterator ends and a default value was passed, it is returned.
- If no default was defined, the error ' StopIteration ' is raised. · An example of how it is used can be seen here: · expression = (x*2 for x in range(5)) · print(next(expression, "No more data")) # Prints 0 · print(next(expression, "No more data")) # Prints 2 · print(next(expression, "No more data")) # Prints 4 · print(next(expression, "No more data")) # Prints 6 · print(next(expression, "No more data")) # Prints 8 · print(next(expression, "No more data")) # Prints "No more data"
- As seen in the previous slide, we were able to create a generator and call each value one by one using next().
- Since we set a default value "No more data', this will be printed if we run out of values from the generator.
- If there is no set default value, then we will encounter an error called ' StopIteration ' instead.

Generator Functions
Generator functions are like regular functions, but they have 'yield' statements in place of 'return' statements.
- A generator function can contain one or more yield statement.
- The difference between the two is that a return statement terminates a function.
- The yield statement pauses the function saving all its states and later continues from there on the next calls.
- Syntax: def my_generator_function(): # Code to generate values yield value
- Let us mimic the example of the generator expression from earlier, but turn it into a generator function: · def function(): · for x in range(5): · yield x*2 · a = function() · print(next(a, "No more data")) # Prints 0 · print(next(a, "No more data")) # Prints 2 · print(next(a, "No more data")) # Prints 4 · print(next(a, "No more data")) # Prints 6 · print(next(a, "No more data")) # Prints 8 · print(next(a, "No more data")) # Prints "No more data"
- As seen in the previous slide, we can make use of the generator function to achieve the same output as the generator expression.
- We simply need to assign our function to an object so that we can 'initialize' the generator.
- This essentially resets the generator when the object is called.
- This is done because when the generator is completely iterated upon, we can no longer restart the iteration for that object.
- We can also iterate through the generator function using a for loop as well. def function(): for x in range(0, 5): yield x*2 a = function() for x in a: print(x) # Prints 0 2 4 6 8
- This allows us to have shorter code for printing out the content of the generator.
- This also automatically stops once the generator is empty.
- The disadvantage here is the we cannot pause halfway through the loop as easily compared to using 'next()'.

Sending objects to a Generator
We can send objects to a generator using the 'send()' command.
- This will allow us to send variables to our generator and have the generator process the value.
- The generator will only process the value when it is called via next() or send().
- An example is shown in the next slide.
- We create a generator which will allow us to stack numbers which are sent to it: · def accumulator(): · total = 0 · value = None · while True: · value = yield total · if value is None: break · total += value · generator = accumulator()
- We create a generator which will allow us to stack numbers which are sent to it: · print(next(generator)) # Prints 0 · print(generator.send(1)) # Prints 1 · print(generator.send(10)) # Prints 11 · print(generator.send(100)) # Prints 111 · print(next(generator)) # Gives an error
- In the example shown, we first call 'next(generator)' to advance to the first yield, where the value we yield is 0.
- We can then send new values to the generator using the 'send()' function.
- Take note that the generator does not keep these values in memory, the 'default' state of the 'value' variable is None, if we use next.
- This is why when we call the generator again using next, it sticks with the default data and ends up stopping the program.
