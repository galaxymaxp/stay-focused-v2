## Cause (Realme evidence)

The installed update before this release (`01a162a3`, FS7) ran the live GL orb
on a cold start, and survived 8 s and 50 s backgrounding plus system night-mode
toggles. After the owner changed Appearance in Settings, logcat showed the
MainActivity window surfaces being destroyed, then `Orb unavailable; keeping
static poster.`, and the view tree held only the padded poster SVG with no
`expo.modules.gl.GLView`. `DayOrb` treated a second `onContextCreate` with a
new context as final failure.
