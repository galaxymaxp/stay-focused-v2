# Stay Focused Android friend beta checklist

1. Install Stay Focused using the APK link provided by the app owner. If Android asks, allow installation from the app you used to open the APK.
2. Open Stay Focused.
3. Sign in, or create the test session the app owner provided.
4. Connect Canvas and sync a course if you have a Canvas account and were asked to do so.
5. Open Today.
6. Open Generate.
7. Open Tasks.
8. Open Library.
9. Open one study material or saved output.
10. Close the app.
11. Reopen it and check whether your session and saved content are still there.
12. If you have saved content, turn on Airplane mode, reopen one saved item, then turn Airplane mode off again.
13. Report anything that seems broken, unreadable, stuck, or confusing.

When reporting an issue, include:

- Phone model
- Android version
- What you were doing
- What you expected to happen
- What happened instead
- The exact visible error text, if any
- A screenshot or screen recording, if possible

Please do not include your password, Canvas access token, or other sign-in secrets in a report.
